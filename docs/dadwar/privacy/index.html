아빠 전쟁 개인정보 처리방침

  • 운영자: 파랑버섯 스튜디오

1. 적용 범위

이 방침은 파랑버섯 스튜디오가 제공하는 ‘아빠 전쟁’에 적용됩니다. Android 광고 테스트 버전에는 Google Mobile Ads와 동의 관리용 User Messaging Platform(UMP)이 포함됩니다. 기존 Windows v0.3 배포본에서는 광고 SDK를 실행하지 않습니다. 회원 가입, 서버 저장, 앱 내 결제 및 별도의 이용 분석 SDK는 연결되어 있지 않습니다.

2. 기기에 저장하는 정보

게임은 진행한 스테이지, 별과 최고 기록, 게임 재화, 장비, 강화, 마지막 플레이 시각과 방치 보상, 소리·진동 등 설정을 이용자의 기기에 저장합니다. 이 정보는 게임 진행 유지와 설정 복원에 사용됩니다. 스튜디오의 서버로 전송하는 기능은 현재 구현되어 있지 않습니다.

기기의 운영체제나 이용자가 선택한 백업 서비스가 앱 데이터를 백업·복원할 수 있으며, 해당 기능은 그 서비스의 설정과 방침에 따릅니다. 스튜디오가 제공하는 계정·클라우드 동기화 기능은 없습니다.

3. 문의 시 제공하는 정보

문의 이메일로 직접 보내신 이메일 주소, 문의 내용과 첨부자료는 답변 및 문제 해결에 사용됩니다. 비밀번호나 결제 수단 정보 같은 민감한 내용을 보내지 마세요. 문의 전송과 메일 보관에는 이용자가 선택한 메일 서비스 및 수신 메일 서비스가 관여합니다.

문의 정보는 답변과 문제 해결에 필요한 기간 동안 보관하고 목적이 달성되면 삭제합니다. 별도의 보관 의무가 있는 경우에는 해당 의무에 필요한 범위와 기간 동안 보관합니다.

4. 제3자 제공과 광고

Android 광고 테스트 버전은 Google이 제공하는 테스트 광고를 요청하며 실제 광고 수익은 발생하지 않습니다. 테스트 광고라도 SDK의 네트워크 요청이 발생할 수 있습니다. 광고·측정·부정 사용 방지 등을 위해 Google SDK가 IP 주소(대략적인 위치 추정에 사용 가능), 광고 관련 상호작용, 진단 정보, 광고 ID·앱 세트 ID 등 기기 식별자를 수집·공유할 수 있습니다. 게임의 로컬 저장 파일을 광고 SDK에 전달하지는 않습니다.

광고 요청 전에 UMP로 동의 상태를 확인하고 필요한 메시지를 표시합니다. SDK가 광고 요청 가능 상태를 반환한 경우에만 광고를 준비합니다. 지역과 동의 상태에 따라 광고 처리 방식이 달라질 수 있습니다. 필요한 경우 게임 설정의 ‘광고 개인정보 선택 변경’에서 선택을 변경할 수 있습니다. Android 설정에서도 광고 ID를 재설정하거나 삭제할 수 있습니다.

Google의 정보 처리·보관·국외 처리 및 권리 행사에 관한 자세한 내용은 Google 개인정보처리방침과 Google 광고 데이터 안내를 확인해 주세요. SDK 통신은 전송 중 TLS로 암호화됩니다. 스튜디오는 Google이 보관하는 SDK 데이터의 사본을 직접 관리하거나 삭제할 수 없으며 관련 요청 경로는 문의 시 안내합니다.

상용 광고·결제·서버 등 처리 방식이 변경되면 이 방침과 스토어 데이터 공개 정보를 실제 구성에 맞게 갱신하고 필요한 안내·동의 절차를 적용합니다.

5. 보관과 삭제

기기에 저장된 게임 정보는 게임 이용과 진행 복원을 위해 유지됩니다. 운영체제의 앱 데이터 삭제 기능으로 삭제할 수 있으며, 앱 삭제·재설치 시의 데이터 유지 및 백업 동작은 운영체제와 백업 설정에 따라 달라질 수 있습니다. 스튜디오는 서버 사본을 보유하지 않아 기기 데이터가 삭제되면 직접 복원해 드릴 수 없습니다.

게임 저장을 읽을 수 없을 때에는 진행 기록을 보호하기 위해 기존 파일에 대한 자동 저장을 중단할 수 있습니다. 이 경우 데이터 삭제 전에 문의해 주세요.

6. 이용자의 문의와 요청

문의 과정에서 제공하신 정보의 열람·정정·삭제 요청과 개인정보 관련 문의는 alstnwjd0424@naver.com으로 보내 주세요. 요청을 확인하고 처리 결과를 안내하겠습니다. 현재 앱에는 계정 생성 기능이 없으므로 별도의 앱 계정 탈퇴 기능은 없습니다.

7. 정보 보호와 변경 안내

스튜디오는 게임 진행 저장 파일을 자체 서버로 전송하지 않으며, 저장 파일 손상에 대비한 기기 내 백업 복구 기능을 제공합니다. Android 광고 SDK의 정보 처리는 위 제4항과 같습니다. 백업은 손상이나 분실에 대한 완전한 복원을 보장하는 기능이 아닙니다.

정보 처리 방식이 바뀌면 시행일과 내용을 갱신하여 앱 내 처리방침 및 공개 처리방침 페이지를 통해 안내합니다. 개인정보 관련 문의 창구는 파랑버섯 스튜디오(alstnwjd0424@naver.com)입니다.
