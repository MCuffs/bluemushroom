# 홈페이지 디자인 기준과 가족 설정

## 중심 이미지

메인은 `docs/assets/game-family.webp`의4인 가족사진이다. 게임 「아빠 전쟁」의 기존 아빠·아들 디자인을 바탕으로 구성한 캐릭터 가족이다. 이 가족의 그림체·굵은 윤곽선·인물 비율을 홈페이지의 시각 기준으로 사용한다. 별도의 미형 만화 인물이나 수채화 가족으로 대체하지 않는다.

## 확정 이름

가족사진의 왼쪽부터 다음 순서다.

| 역할 | 이름 |
| --- | --- |
| 아빠 | 칠석 |
| 형 | 철수 |
| 막내 동생 | 만수 |
| 엄마 | 수진 |

사용자가 확정한 이름이며 홈페이지의 소개 문구·대체 텍스트·사진 아래 이름표에 동일하게 사용한다. 엄마는 사용자가 승인한 날씬한 최종 외형을 유지한다. 게임 저장소의 기존 대사/이름을 이 작업에서 일괄 변경한 것은 아니다.

## 시각 원칙

- 페이지 배경은 순백색 `#ffffff`. 종이 노이즈·누런 바탕·넓은 색상 띠는 사용하지 않는다.
- 가족사진은 본래 거실 배경과 색을 유지한다. 흰색 페이지 위에서 가족사진이 주인공이 된다.
- 굵은 게임 글꼴(Black Han Sans)과 읽기 편한 본문(Gothic A1), 가는 구분선과 여백을 사용한다.
- 올리브·노랑·파랑은 캐릭터/작은 강조 요소에만 사용한다.
- 가족의 따뜻하고 두런두런한 분위기와 실제 게임 사이의 일관성을 우선한다.
- 공식 문의 주소·검색 인증·개인정보 경로와 기존 앵커는 보존한다.
