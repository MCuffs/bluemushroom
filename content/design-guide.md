# 홈페이지 디자인 기준과 가족 설정

## 중심 이미지

메인은 `docs/assets/game-family.webp`의4인 가족사진이다. 게임 「아빠 전쟁」의 기존 아빠·아들 디자인을 바탕으로 구성한 캐릭터 가족이다. 이 가족의 그림체·굵은 윤곽선·인물 비율을 홈페이지의 시각 기준으로 사용한다. 별도의 미형 만화 인물이나 수채화 가족으로 대체하지 않는다.

## 확정 이름

가족사진의 왼쪽부터 다음 순서다.

| 역할 | 이름 |
| --- | --- |
| 아빠 | 칠석 |
| 형 | 철수 |
| 막내 동생 | 만수 |
| 엄마 | 수진 |

사용자가 확정한 이름이며 홈페이지의 소개 문구·대체 텍스트·사진 아래 이름표에 동일하게 사용한다. 엄마는 사용자가 승인한 날씬한 최종 외형을 유지한다. 게임 저장소의 기존 대사/이름을 이 작업에서 일괄 변경한 것은 아니다.

## 시각 원칙

- 페이지 배경은 순백색 `#ffffff`. 종이 노이즈·누런 바탕·넓은 색상 띠는 사용하지 않는다.
- 가족사진은 본래 거실 배경과 색을 유지한다. 흰색 페이지 위에서 가족사진이 주인공이 된다.
- 굵은 게임 글꼴(Black Han Sans)과 읽기 편한 본문(Gothic A1), 가는 구분선과 여백을 사용한다.
- 올리브·노랑·파랑은 캐릭터/작은 강조 요소에만 사용한다.
- 가족의 따뜻하고 두런두런한 분위기와 실제 게임 사이의 일관성을 우선한다.
- 공식 문의 주소·검색 인증·개인정보 경로와 기존 앵커는 보존한다.

## 캐주얼 디자인과 출시 예정 라인업

흰색 바탕과 가족사진을 유지하고 둥근 카드·버튼, 연한 파스텔 카드, 파랑버섯 로고, 가족 얼굴 썸네일을 사용한다. 왼쪽 책갈피 인덱스 대신 상단의 주요 메뉴로 이동한다. 얼굴 썸네일은 원본 가족사진에서 잘라 낸 그림(`public/assets/face-*.webp`)을 사용하며 새 인물로 바꾸지 않는다.

출시 예정작은 games-lineup.json과 games-roadmap.md를 기준으로 한다. 아빠 전쟁의 개발 상태와 후속작의 기획 상태를 구분하고, 확정되지 않은 출시일이나 스토어 링크를 만들어 넣지 않는다.

## 구현 기준 (2026-11-17)

첫 화면을 Meta의 Astryx 디자인 시스템 부품으로 다시 구성했다. 위의 가족사진·확정 이름·흰색 바탕·글꼴·출시 상태 표기 기준은 그대로 적용한다.

- 색, 글자 크기, 둥글기, 간격은 테마 `family`(`themes/family/`)의 값만 쓴다. 색상 코드나 px 값을 화면 코드에 직접 적지 않는다.
- 글자 크기는 6단계, 가장 작은 글자는 13px이다. 본문과 라벨의 색은 배경 대비 4.5:1 이상을 지킨다.
- 강조색은 올리브(`#4f7539`)이며 주 버튼·링크·작은 라벨에 쓴다. 카드의 바탕색은 Astryx의 색 카드(노랑·초록·주황·파랑)를 쓴다.
- 휴대폰에서 버튼과 접기 제목의 누르는 높이는 44px 안팎으로 둔다.
- 이전 화면에 있던 노란 버튼, "우리, 넷." 스티커, 기울어진 포스터 카드, 구역 번호 라벨은 해당 부품이 없어 지금 화면에 없다.
